# Project Notes

This is a compact, self-contained Godot 4.x prototype intended to bring the Week 1–7 activity goals together.

- Main scene: `scenes/main.tscn`
- Player movement, shooting, animations and particles: `scripts/player.gd`
- Projectile movement and collision: `scripts/projectile.gd`
- Enemy finite state machine: `scripts/enemy.gd`
- Level generation, HUD, menu, audio, save/load and screen shake: `scripts/main.gd`
- Save data is stored locally at `user://puzzle_shoot_save.json`.
